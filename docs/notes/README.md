# Notes behind the methods

Reading notes and computed tables that `docs/methodology.md` draws on. The book is Truong and
Koyejo (2026), "AI Measurement Science", the course textbook; it is not in the repo, so notes cite
it by section and page.

| Note | What it covers |
|---|---|
| `book_validity_and_causality.md` | Validity evidence and threats (ch. 1), causal framing (ch. 9), the ch. 13.5 checklist applied to this design |
| `book_response_matrices_and_rasch.md` | Paired response matrices, Rasch/IRT, estimation with 5 models |
| `book_reliability_dif_and_factors.md` | Reliability, DIF, factor models and MTMM (ch. 5), and why DIF and a two-factor model are not used here |
| `book_gtheory_and_run_sizing.md` | G-study and D-study (ch. 5) as used to size the first block and the run count |
| `gtheory_methods.md` | Variance-component estimators, G and Phi, the gap as a difference score, run and item sizing |
| `lit_llm_eval_variance.md` | Papers on run-to-run noise, paired standard errors and item sampling in LLM evals |
| `lit_code_eval_statistics.md` | Papers on the statistical analysis of code benchmarks |
| `lit_rendered_text_and_code.md` | How published papers evaluate VLMs on text or code rendered as images |
| `lit_main_results_comparison.md` | How each main-analysis finding compares with that related work |
| `token_costs.md` | Pages per item and image-to-text token ratios per model at 10, 12 and 14 px |
